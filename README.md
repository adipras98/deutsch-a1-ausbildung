# Siap Jerman A1

Aplikasi persiapan ujian bahasa Jerman level A1 (Goethe-Zertifikat A1) untuk calon Ausbildung dari Indonesia.

## Fitur versi pertama
- Kartu hafalan kosakata (Perkenalan Diri, Dunia Kerja, Kehidupan Sehari-hari) dengan suara pengucapan
- Latihan Lesen dengan penjelasan bahasa Indonesia
- Simulasi ujian Lesen dengan timer dan skor

## Menjalankan
```
npm install
npm run dev
```

Semua soal dibuat sendiri (original). Aplikasi ini independen dan tidak berafiliasi dengan Goethe-Institut.
